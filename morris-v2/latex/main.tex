\section{Overview}\label{sec:overview}
\begin{figure}[h!]
    \centering
    \includegraphics[width=0.7\linewidth]{img/mv2_cad.png} 
    \caption{The CAD model of MV2.}
    \label{fig:mockup}
\end{figure}

The MV2 robot has been designed as a low-cost 6-axis serial manipulator that can be easily tailored to use different control systems and end-effectors. The robot follows the standard joint arrangement seen on many industrial 6-DOF manipulators, with a 2R open-chain attached to a rotating base used as the positioning system for a spherical wrist.

\section{Kinematics}
\begin{figure}[h!]
    \centering
    \includegraphics[width=0.7\linewidth]{img/mv2_joint-diagram.png}
    \caption{Joint diagram of the MV2 robot.}
    \label{fig:joint_diagram}
\end{figure}

Figure~\ref{fig:joint_diagram} shows the joints of the MV2 robot. $\theta_{1}$, $\theta_{2}$, and $\theta_{3}$ comprise the positioning joints; $\theta_{4}$, $\theta_{5}$, and $\theta_{6}$ comprise the orienting joints, constructed in the spherical wrist configuration.

\begin{figure}[h!]
    \centering
    \includegraphics[width=0.65\linewidth]{img/mv2_link2-offset.png} 
    \caption{Diagram of $y$-axis and $z$-axis offset distances between joint 2 and joint 3.}
    \label{fig:j2_j3_offset}
\end{figure}

The only notable deviation from this structure on the MV2 is that when the robot is in its rest position, there is an angled offset between joint 2 and joint 3. This can be seen in Figure~\ref{fig:j2_j3_offset}, which shows a side view of MV2 with the aesthetic shell of its second link removed. The offset has been marked with distances $L_{2y}$ and $L_{2z}$, and $\theta$ as the resulting offset angle. As such, any kinematic models of the robot must take into account this offset. All other joints are collinear and/or coaxial where relevant.

\subsection{Forward Kinematics}

The forward kinematics of MV2 can be defined using the Power of Exponentials formula discussed by Lynch and Park in Modern Robotics, \cite{modernrobotics}.

As per Figure~\ref{fig:joint_diagram}, define:
\begin{itemize}
    \item $h$ as the distance between the ground and $\theta_{1}$;
    \item $L_{1}$ as the distance between $\theta_{1}$ and $\theta_{2}$;
    \item $L_{3}$ as the distance between $\theta_{3}$ and $\theta_{4}$;
    \item $L_{4}$ as the distance between $\theta_{4}$ and $\theta_{5}$;
    \item $L_{5}$ as the distance between $\theta_{5}$ and $\theta_{6}$;
    \item and $L_{6}$ as the distance between $\theta_{6}$ the end-effector.
\end{itemize}
$L_{2}$ is defined as the components $L_{2y}$ and $L_{2z}$, as per Figure~\ref{fig:j2_j3_offset}. Screw axes $\mathcal{S}_{n}$ can then be defined for each joint as follows:
\begin{align*}
    \mathcal{S}_{1} = \begin{bmatrix}
    0 \\ 0 \\ 1 \\ 0 \\ 0 \\ h    
    \end{bmatrix}, \quad
    \mathcal{S}_{2} = \begin{bmatrix}
    1 \\ 0 \\ 0 \\ 0 \\ 0 \\ h + L_{1}   
    \end{bmatrix}, \quad
    \mathcal{S}_{3} = \begin{bmatrix}
    1 \\ 0 \\ 0 \\ 0 \\ -L_{2y} \\ h + L_{1} + L_{2z}   
    \end{bmatrix}
\end{align*}

\begin{align*}
    \mathcal{S}_{4} = \begin{bmatrix}
    0 \\ -1 \\ 0 \\ 0 \\ -L_{2y} + L_{3} \\ h + L_{1} + L_{2z}
    \end{bmatrix}, \quad
    \mathcal{S}_{5} = \begin{bmatrix}
    1 \\ 0 \\ 0 \\ 0 \\ -L_{2y} + L_{3} + L_{4} \\ h + L_{1} + L_{2z}
    \end{bmatrix}, \quad
    \mathcal{S}_{6} = \begin{bmatrix}
    0 \\ -1 \\ 0 \\ 0 \\ -L_{2y} + L_{3} + L_{4} + L_{5} \\ h + L_{1} + L_{2z}
    \end{bmatrix}
\end{align*}

and the end-effector transformation at rest, $M$ can be defined as
\begin{align*}
    M = \begin{bmatrix}
        1 & 0 & 0 & 0 \\
        0 & 1 & 0 & -L_{2y} + L_{3} + L_{4} + L_{5} + L_{6} \\
        0 & 0 & 1 & h + L_{1} + L_{2z} \\
        0 & 0 & 0 & 1 \\
    \end{bmatrix} \in SE(3)
\end{align*}

which can be used in the PoE formula:
\begin{align}\label{eq:poe_formula}
    T(\theta) &= 
    e^{\displaystyle [\mathcal{S}_{1}]\theta_{1}}
    e^{\displaystyle [\mathcal{S}_{2}]\theta_{2}}
    e^{\displaystyle [\mathcal{S}_{3}]\theta_{3}}
    e^{\displaystyle [\mathcal{S}_{4}]\theta_{4}}
    e^{\displaystyle [\mathcal{S}_{5}]\theta_{5}}
    e^{\displaystyle [\mathcal{S}_{6}]\theta_{6}}
    M \in SE(3),\\
    \theta &= \begin{bmatrix}
        \theta_{1} & \theta_{2} & \theta_{3} & \theta_{4} & \theta_{5} & \theta_{6} 
    \end{bmatrix}^{T} \in \mathbb{R}^{6} \nonumber
\end{align}

        \hline
    \end{tabular}

\footnotetext{Technically, $\theta_{1}$ and $\theta_{2}$ both use the Miuzei MS24 20kg Digital Servo, which has an angle range of $270^{\circ}$, however for consistency, ease of use, and to simplify the construction, the servo has simply been taken as having the same $180^{\circ}$ limit as the MG996R servos used in the other joints.\label{fn:270_servo}}

As the robot is constructed using servos for actuation, the joints are not continuous and have specific limits. These can be seen in Table~\ref{tab:joint_limits}. The reference axes and subsequent rest positions for each joint are based on the servos themselves rather than the mathematical model of Equation~\ref{eq:poe_formula}. The reference axes are defined as per the axes shown in Figure~\ref{fig:joint_diagram}.

\section{Electronics \& Software}

\begin{figure}[h!]
    \centering
    \includegraphics[width=0.6\linewidth]{img/mv2_elec-mounts.png}
    \caption{Positions of the electronics mounting holes.}
    \label{fig:elec_mounts}
\end{figure}

MV2 has been designed such that it is not tied directly to one microcontroller platform. The base of MV2 has been designed with an open back, and four mounting holes, as seen in Figure~\ref{fig:elec_mounts}, which can be used to fit custom 3D printed baseplate extensions to hold whichever microcontroller and power boards the user may wish to use.

The only electronics contained within the base link (aside from the joint 1 motor) is an Adafruit-style PCA9685 16-Channel 12-Bit PWM servo driver board. Mounting holes have been included for this board as it was considered the most basic element needed to control the robot, however should they wish, the open design of the base means that the user is free to forego this board in favour of an alternative.

\begin{figure}[h!]
    \centering
    \includegraphics[width=1.0\linewidth]{img/mv2_schematic.png}
    \caption{Schematic of the MV2 UNO-R3 based electronics.}
    \label{fig:schematic}
\end{figure}

\subsection{UNO R3 Setup}
As a basic "default" setup, the MV2 repository includes a mount and control script for controlling the robot using an Arduino UNO R3 microcontroller. The formal schematic for this is shown in Figure~\ref{fig:schematic}, however it may also be clearer to some users to simply state the connections, which are as follows:
\begin{itemize}
    \item UNO R3: 5V \rightarrow PCA9685: VCC
    \item UNO R3: GND \rightarrow PCA9685: GND
    \item UNO R3: SCL \rightarrow PCA9685: SCL
    \item UNO R3: SDA \rightarrow PCA9685: SDA
    \item Motors 1, 2, 3, 4, 5, 6 to PCA9685 channels 0, 1, 2, 3, 4, 5 respectively.
\end{itemize}

Note that this setup assumes the UNO R3 model that includes dedicated SDA and SCL pins for I2C.

A script is included in the UNO R3 setup, in the form of an Arduino IDE sketch named \texttt{mv2\_control\_uno-r3.ino}. This script allows the MV2 robot to be controlled using commands over serial, and makes use of acceleration ramps in order to reduce oscillations in the robot's movements. The script has three commands, which are:

\begin{itemize}
    \item \fbox{\texttt{joint [channel] [target angle] [time to move in milliseconds]}} \\
    
    Tells a specific joint motor (based on its PCA9685 channel) to move to a target angle in some set amount of time.
    
    Example: \texttt{joint 2 60 1500}
    
    The above will tell the elbow joint to move to $60^{\circ}$ in 1.5 seconds. It is recommended to try and keep movement times to a minimum of 1000 milliseconds.


    \item \fbox{\texttt{home [time to move in milliseconds]}} \\
    
    Tells the robot to move to its rest, or home, position in some set amount of time.
    
    Example: \texttt{home 3000}
    
    The above will tell the robot to move to its rest position in 3 seconds. It is recommended that when writing serial control code (for example, in Python) that you use this command as the exit state of your script to avoid the robot jerking into its rest position each time you reset the control script.


    \item \fbox{\texttt{stance [time to move in milliseconds]}} \\
    
    Tells the robot to move to its "stance" position in some set amount of time.
    
    Example: \texttt{stance 2000}
    
    The above will tell the robot to move to its rest position in 2 seconds. This can be a useful command for verifying that the robot's joints are working correctly.
\end{itemize}

\section{Assembly}

MV2 is a 3D printed robot. The robot has been designed to be printed using PLA at 10\% to 20\% infill, however any reasonably hard filament should function as well. The \texttt{.stl} files for MV2 can be found in the \texttt{/parts/} folder of the MV2 repository. Assembly drawings can be found in the \texttt{.pdf} file named \texttt{mv2-drawings\_assembly.pdf}.

Aside from 3D printed parts, MV2 uses various purchased components. The list of these can be seen in Table~\ref{tab:bom}

When assembling motor and horn stabiliser pairs, the Arduino IDE sketch named \texttt{mv2\_servo-zeroing.ino} should be used to ensure that all servos are in their correct home positions when the links are all assembled together.
